📖 Как пользоваться

🏋️ Тренировки

Создать: «+ Тренировка» → название, период (с — по), дни недели, время. Появится в календаре только в этом периоде.

Пусто в периоде = бессрочно.

Упражнения: «+ Упражнение» (готовое) или «+ Комплекс» (набор).

▶ Запуск: рядом с карточкой тренировки кнопка ▶ открывает режим выполнения с таймером.

✓ Отметить: только сегодня и прошлое. Будущее заблокировано.

⭐ X-параметры

В дозировке упражнения можно вписать X вместо цифры. Тогда при запуске тренировки приложение спросит значение перед началом упражнения. Например: «подходы: X» → спросит «сколько подходов сделал?».

💪 Упражнения

У каждого — несколько зон, снарядов, навыков.

Формат XP: ⏱ Время (сек×0.01), 🏋️ Вес (вес/масса×0.01×повт), 💪 Свой вес (повт×0.1).

🔁 Комплексы

Наборы упражнений. Кнопка «📋 Комплексы» в нижнем баре — просмотр, редактирование, удаление. В тренировке: «+ Комплекс» добавит весь набор.

🎒 Свои снаряды

«+ Свой снаряд» под чипсами снарядов → название + эмодзи из сетки.

⭐ XP

Уровень N → N+1 = N XP. 8 рангов: Новичок → Легенда.

🌙 Распад

Если снаряд/зона/навык не тренируется 7+ дней — XP падает (−0.1…−1%/день).

💾 Данные

Всё в localStorage. Периодически экспортируй базу (Профиль → 📤).
