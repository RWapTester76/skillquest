📖 Как пользоваться

🏋️ Тренировки

Создать: «+ Тренировка». Название, период (С/По), дни недели, время.

Если период пустой — тренировка действует бессрочно.

Упражнения: «+ Упражнение» (готовое) или «+ Комплекс» (набор).

Правки на день: открой тренировку в конкретный день → ✏️ у упражнения. Сохранится только для этой даты.

✅ Выполнение

✓ — отметить сделанной, начисляется XP. Только сегодня и в прошлое. Будущее под замком 🔒.

▶ — запустить с таймером и пошаговым прохождением. В конце «Засчитать» — автоматически ставит ✓.

Снятие ✓ отнимает XP. Но PR не откатывается.

🎯 Зоны — главные и подзоны

13 главных зон (Плечи, Спина, Грудь и т.д.) и подзоны внутри (Передняя дельта, Широчайшие, Верх груди...).

XP считается так: уровень главной зоны = свой XP + сумма подзон. В детальной статистике видно, какая подзона отстаёт (⚠).

Создать подзону: в фильтре «Зоны» раскрой группу → «+ подзона». Или «+ Своя зона» внизу.

Своя главная зона: в модалке создания выбери «Сделать главной зоной».

⭐ X-параметры

В дозировке упражнения введи X вместо числа. Перед началом спросит значение.

💪 Упражнения

Мульти-теги: несколько зон/снарядов/навыков. Медиа: несколько фото + видео + ссылка.

⏱ Время: XP = сек × 0.01

🏋️ Вес: XP = (вес/масса) × 0.01 × повторы

💪 Свой: XP = повторы × 0.1

📋 Комплексы

Набор упражнений с дозировками. В тренировке: «+ Комплекс» вставляет весь набор.

🏆 Личные рекорды (PR)

При отметке ✓ проверяются рекорды. Побил — золотой баннер. Типы: макс вес / макс повторы / макс время.

Смотри все PR и графики в XP → «📈 Прогресс упражнения».

⚖️ Журнал веса

Профиль → «Открыть журнал». Используется в формуле XP для упражнений с весом.

⭐ XP и уровни

Уровень N → N+1 требует N XP. 8 рангов: Новичок → Легенда (100+).

4 прокачки: атлет + каждый снаряд + каждая зона (с подзонами) + каждый навык.

🌙 Распад

7-13 дней: −0.1%/день · 14-29: −0.25% · 30-59: −0.5% · 60+: −1%.

🎨 Темы

10 тем, у каждой день/ночь. Тумблер ☀️/🌙 в шапке.
