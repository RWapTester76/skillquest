📱 О приложении

💪
Делать Упражнения
Личный трекер тренировок с геймификацией

🎯 Зачем это

Помогает планировать тренировки, выполнять по шагам и видеть прогресс — по каждой зоне, снаряду и навыку. Геймификация (XP, ранги, распад) держит мотивацию.

📅 Календарь

• Неделя на главном экране, месяц — всплывающий

• Гибкий период С/По — разово или бессрочно

• Дни недели + время + длительность

• В календаре — только просмотр; редактирование через «Шаблоны»

• Прошлое — отмечается, будущее 🔒

🏋️ Упражнения

• Фото/видео + ссылка

• Три иконки-категории: Зоны / Снаряды / Навыки → каждая открывает плитки с иконками

• Форматы XP: ⏱ время · 🏋️ вес×повторы · 💪 свой вес

• X для повторов и веса — спрашивается после каждого подхода

• X для подходов, времени, отдыха — спрашивается перед упражнением

• Две стороны — счёт и таймеры учитывают обе стороны (×2)

🔍 Поиск

• В меню «Упр.» — поле поиска по названию

• В меню «Комплексы» — поиск по карточкам

• При выборе комплекса в тренировку — поле «Поиск комплекса»

🎯 Плитки-фильтры

Кнопки «Зоны / Снаряды / Навыки» открывают плитки. Клик на главную зону с подзонами → вторая страница с конкретными пучками. Нажал — фильтр применился. «Сбросить» очищает всё.

🔁 Комплексы

Готовые наборы вставляются в любую тренировку.

Круговой режим: включите «На количество кругов» и задайте время. Атлет жмёт «Круг завершён» — круг считается.

Нестандартный отдых: для режима «по подходам» можно задать массив отдыха между подходами (например 60,90,120) для каждого упражнения отдельно.

Сортировка: упражнения в редакторе перетаскиваются за ручку ⠿.

▶️ Выполнение

Пошаговый проход, таймер работы/отдыха, звук и вибрация, точки подходов, «Пропустить», авто-XP и PR-баннеры.

🎯 Зоны тела

Главные + подзоны: плечи (дельты, бицепс, трицепс), спина (широчайшие, трапеция, ромбовидные, поясница), грудь (верх/середина/низ), ягодицы (большая/средняя/малая), бёдра (квадрицепс, бицепс бедра, приводящие, отводящие), голень (икра, камбала, берцовые), пресс (прямая, поперечная, косые), кисти (сгибатели, разгибатели). Плюс: кардио, лицо, шея, стопы, кор, растяжка. XP главной = своя + сумма подзон. Слабая подзона помечается ⚠.

⭐ XP и ранги

• Формулы: сек×0.01 · (вес/масса)×0.01×повт · повт×0.1

• Ранги: Новичок → Любитель → Атлет → Спортсмен → Мастер → Ветеран → Чемпион → Легенда

• Распад при простое: −0.1%/день (7+ дн) … −1%/день (60+ дн)

🏆 Личные рекорды

Автодетект при отметке. Побил — золотой баннер.

📊 Аналитика

Графики вес/объём/повторы/время, персонаж, отдельно снаряды/зоны/навыки. Меню — большие иконки сверху.

⚖️ Журнал веса

Запись по датам, график, мин/макс. Профиль берёт массу из последней записи.

📏 Обхваты тела

13 частей тела с табами: шея, грудь, талия, живот, бёдра, бёдра/голени/бицепсы/предплечья слева/справа.

Анализ композиции: индексы Грудь/Талия, Талия/Бёдра, Бёдра/Талия, Шея/Талия, Бицепс/Талия.

💾 Данные

localStorage. Экспорт/импорт JSON, Share, буфер. Резервная копия — раз в неделю.

📖 Как пользоваться

🏋️ Тренировки

Создать: «+ Тренировка». Заполни название, период (С/По), дни недели, время.

Если период пустой — тренировка действует бессрочно.

Упражнения: «+ Упражнение» или «+ Комплекс».

Порядок меняется перетаскиванием за ручку ⠿ в редакторе.

✅ Выполнение

✓ — отметить сделанной. Только сегодня и в прошлое. Будущее под замком 🔒.

▶ — запустить с таймером. В конце «Засчитать» ставит ✓ автоматически.

⭐ X-параметры

Подходы, время, отдых — спросим перед упражнением (один раз).

Повторы, вес — спросим после каждого подхода. Если предыдущий подход был заполнен, его значение подставляется как дефолт — можно просто нажать Enter.

Для двусторонних упражнений повторы спрашиваются «на одну сторону».

🎯 Плитки-фильтры и категории

В меню «Упр.» кнопки «Зоны / Снаряды / Навыки» открывают плитки для фильтра списка упражнений.

В редакторе упражнения три кнопки-категории открывают подменю с плитками для выбора тегов.

🔁 Круговой режим

При создании комплекса переключите «На количество кругов» и задайте время (напр. 20 мин).

В тренировке такой комплекс встаёт блоком. Жмите «Круг завершён» — счётчик кругов растёт, таймер идёт вниз.

XP = XP за 1 круг × число кругов. При отметке ✓ вручную спросит «Сколько кругов?».

📊 Нестандартный отдых

В комплексе «по подходам» включите «Нестандартный» — в каждом упражнении появится поле «Отдых после подходов».

Пример: 60,90,120 = отдых 60с после 1-го подхода, 90с после 2-го, 120с после 3-го.

📅 Календарь месяца

Кнопка «📅 Календарь месяца» открывает всплывающее окно с полным месяцем.

Выбрал день — модалка закрылась, неделя и тренировки обновились.

📏 Обхваты

В профиле «Открыть журнал обхватов». Табы по частям тела, ввод значения, график, список.

💪 Упражнения

Мульти-теги: несколько зон/снарядов/навыков. Медиа: несколько фото + видео + ссылка.

⏱ Время: XP = сек × 0.01 · 🏋️ Вес: (вес/масса) × 0.01 × повторы · 💪 Свой: повторы × 0.1

Две стороны: XP ×2, в выполнении «Сторона 1 / Сторона 2».

🏆 Личные рекорды (PR)

При отметке ✓ проверяются рекорды. Побил — золотой баннер. Для X-повторов PR берётся как максимум из массива.

🌙 Распад

7-13 дней: −0.1%/день · 14-29: −0.25% · 30-59: −0.5% · 60+: −1%.

💾 Данные

Всё в localStorage. Экспорт/импорт через профиль. Делай резервную копию.
